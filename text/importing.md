# Import
An `import` statement allows access to one of Python's many modules. For example, the `math` module defines a variety of mathematical functions and variables.

For some module called `library`:

`import library` makes the functions from `library` available. A function `f` in that module could be called as `library.f`.

`import library as lib` does the same thing, but with the shorter name `lib`. In this case, `f` could be called as `lib.f`.

`from library import f` makes `f` available as `f`.
